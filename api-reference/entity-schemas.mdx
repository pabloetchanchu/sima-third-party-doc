## Resumen

Cada tabla describe los campos principales de una entidad. Para el schema completo de cada endpoint, usá la [referencia interactiva](/api-reference/overview). Estas tablas cubren los recursos más usados en integraciones.

<Info>
  **Lectura vs escritura:** los campos marcados como *Solo lectura* vienen en las respuestas GET pero no deben enviarse (o se ignoran) en POST/PATCH.
</Info>

---

## Orden de Trabajo (Work Order)

Endpoint de lectura: `GET /api/v3/third_party/work_orders`  
Endpoint de escritura: `POST /integration/api/v1/workOrders`

### Header

| Campo | Tipo | Obligatorio | Editable | Descripción |
|---|---|---|---|---|
| `local_id` | integer | No (auto) | Solo lectura | ID interno de SIMA |
| `external_id` | string | No | Sí | ID de tu sistema |
| `system_id` | string | Sí | Sí | Siempre `"third_party"` |
| `name` | string | Sí | Sí | Nombre descriptivo de la OT |
| `date` | datetime | Sí | Sí | Fecha/hora de la operación (ISO8601) |
| `voucher_date` | datetime | Sí | Sí | Fecha del comprobante |
| `state.pending` | boolean | Sí | Sí | OT pendiente de ejecución |
| `state.executed` | boolean | Sí | Sí | OT ejecutada en campo |
| `state.confirmed` | boolean | Sí | Sí | OT confirmada en SIMA |
| `extra_fields.company.local_id` | integer | Sí | Sí | ID de la empresa/sociedad |
| `extra_fields.voucher_type.local_id` | integer | Sí | Sí | Tipo de comprobante |
| `is_read_only` | boolean | No | Solo lectura | Si `true`, no se puede modificar |

### Supply (aplicación de agroquímico)

| Campo | Tipo | Obligatorio | Editable | Descripción |
|---|---|---|---|---|
| `cultivation.local_id` | integer | Sí | Sí | Cultivo objetivo |
| `formulated.local_id` | integer | Sí | Sí | Producto agroquímico |
| `area_applied` | number | Sí | Sí | Hectáreas aplicadas |
| `total_applied` | number | Sí | Sí | Cantidad total aplicada |
| `date` | datetime | Sí | Sí | Fecha de aplicación |
| `state` | object | Sí | Sí | `{ pending, executed, confirmed }` |

### Labour (labor de campo)

| Campo | Tipo | Obligatorio | Editable | Descripción |
|---|---|---|---|---|
| `cultivation.local_id` | integer | Sí | Sí | Cultivo objetivo |
| `area_applied` | number | Sí | Sí | Hectáreas |
| `contractors[].local_id` | integer | No | Sí | Contratista(s) |
| `machines[].local_id` | integer | No | Sí | Máquina(s) |
| `applicators[].local_id` | integer | No | Sí | Aplicador(es) |
| `date` | datetime | Sí | Sí | Fecha de la labor |
| `state` | object | Sí | Sí | `{ pending, executed, confirmed }` |

## Cultivo / especie (Cultivation)

Endpoint: `GET /api/v3/third_party/cultivations` (catálogo, solo lectura)

| Campo | Tipo | Obligatorio | Editable | Descripción |
|---|---|---|---|---|
| `id` | integer | Auto | Solo lectura | ID interno de la especie |
| `name` | string | — | Solo lectura | Nombre traducido (Soja, Maíz, …) |
| `created_at` / `modified_at` / `deleted_at` | datetime | Auto | Solo lectura | Auditoría |
| `active` | boolean | Auto | Solo lectura | Activo/inactivo |

No confundir con **campaña** (`campaigns`), que es la instancia en un lote y lo que referencian las OTs.

## Campaña (Campaign)

Endpoint: `GET /api/v3/third_party/campaigns`

| Campo | Tipo | Obligatorio | Editable | Descripción |
|---|---|---|---|---|
| `id` | integer | Auto | Solo lectura | ID interno; es el `cultivation.local_id` de las OTs |
| `plot_id` | integer | — | Solo lectura | Lote |
| `master_campaign_id` | integer | — | Solo lectura | Planificación (especie + época + ciclo) |
| `formulated_id` | integer | — | Solo lectura | Variedad / semilla del catálogo de formulados |
| `planting_date` | datetime | — | Solo lectura | Fecha de siembra real |
| `schedule_planting_date` | datetime | — | Solo lectura | Siembra planificada |
| `planting_objective_area_ha` | number | — | Solo lectura | Hectáreas objetivo |
| `objective_yield_kg_ha` | number | — | Ver import v2 | Rendimiento objetivo (escritura async en [avances](/guides/progress-reports)) |
| `harvest_final_yield` | number | — | Solo lectura | Rendimiento final |
| `planting_finished` / `harvest_finished` | boolean | — | Solo lectura | Cierre de siembra / cosecha |
| `external_code` | string | — | Sí (si hay escritura) | Código de tu ERP |
| `created_at` / `modified_at` / `deleted_at` | datetime | Auto | Solo lectura | Auditoría |
| `active` | boolean | Auto | Solo lectura | Activo/inactivo |

## Scouting (sesión de campo)

Endpoint: `GET /api/v3/third_party/scouting` (solo lectura)

| Campo | Tipo | Obligatorio | Editable | Descripción |
|---|---|---|---|---|
| `id` | integer | Auto | Solo lectura | ID de la sesión |
| `campaign_id` | integer | — | Solo lectura | Campaña monitoreada |
| `phenological_state_id` | integer | — | Solo lectura | Etapa del cultivo |
| `hydric_state_id` | integer | — | Solo lectura | Estado hídrico |
| `plot_state_id` | integer | — | Solo lectura | Estado del lote |
| `semaphore` | integer | — | Solo lectura | `1` verde / `2` amarillo / `3` rojo |
| `samples_taken` | integer | — | Solo lectura | Muestras tomadas |
| `scouting_protocol_results` | array | — | Solo lectura | `adversity_id`, `measure_id`, `agg_result_value`, `semaphore` |
| `created_at` / `modified_at` / `deleted_at` | datetime | Auto | Solo lectura | Auditoría |

Catálogos asociados (solo lectura): `hydric_states`, `phenological_states`, `plot_states`, `scouting_measures`.

## Silobolsa

Lectura: `GET /api/v3/third_party/silobags` — ver [Silobolsas](/guides/silobags)

| Campo | Tipo | Obligatorio | Editable | Descripción |
|---|---|---|---|---|
| `id` | integer | Auto | Solo lectura | ID interno |
| `code` | string | — | Solo lectura | Código de la bolsa |
| `silobag_longitude` | string/number | — | Solo lectura | Largo de la bolsa (m), no el GPS |
| `latitude` / `longitude` | string | — | Solo lectura | GPS |
| `date_extracted` | datetime | — | Solo lectura | Extracción (`null` = en uso) |
| `rebagged` | boolean | — | Solo lectura | Reembolsada |
| `semaphore` | integer | — | Solo lectura | `1` / `2` / `3` |

### Silobag scouting

`GET /api/v3/third_party/silobag_scoutings` — `silobag_id`, `scouting_type` (`1` monitoreo, `2` extracción), `semaphore_silo`, `semaphore_cereal`, `extracted_tn`.

### Silobag campaign

`GET /api/v3/third_party/silobag_campaigns` — `silobag_id`, `campaign_id`, `quantity_tn`, `grain_humidity_percent`, `grain_quality_semaphore`.

## Etiqueta, asociación y waypoint

Solo lectura de tags; waypoints permiten **POST** de alta. Endpoints: `/api/v3/third_party/tags`, `tag_associations`, `waypoints`.

### Tag

| Campo | Tipo | Descripción |
|---|---|---|
| `id` | integer | ID interno |
| `name` / `full_name` | string | Nombre y ruta jerárquica |
| `table_code_id` | integer | Tipo de entidad etiquetable |
| `parent_id` | integer \| null | Tag padre |
| `leaf` | boolean | Si es hoja del árbol |

### Tag association

| Campo | Tipo | Descripción |
|---|---|---|
| `id` | integer | ID interno |
| `entity_id` | integer | Recurso etiquetado |
| `table_code_id` | integer | Tipo de recurso |
| `tag_id` | integer | Etiqueta |

### Waypoint

| Campo | Tipo | Descripción |
|---|---|---|
| `id` | integer | ID interno |
| `parent_id` / `parent_type` | integer / string | Entidad dueña (scouting, silobolsa, etc.) |
| `latitude` / `longitude` | number | GPS |
| `sample_number` | integer | Número de muestra |
| `waypoint_kind` | integer | Tipo de punto |
| `acurracy` | number | Precisión (el nombre del campo en API es `acurracy`) |
| `firebase_storage_url` | string | Foto / adjunto |
